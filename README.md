# Alphafairings

Prémiový a vysoce interaktivní katalog závodních dílů na motocykly s přímým odkazem na výrobce.

## Vlastnosti

- 🏍️ **Katalog superbiků:** Rychlé filtrování dílů kompatibilních s modely jako Ducati Panigale V4 R, Yamaha YZF-R1, BMW S1000RR a další.
- ⚙️ **Kategorie dílů:** Výfuky, brzdy, odpružení, podvozek, kapotáže, motor a elektronika.
- 🛠️ **Administrátorský režim (Admin Mode):** Vizuální rozhraní pro přidávání, úpravu a mazání dílů přímo v prohlížeči (data se ukládají do `localStorage`).
- 💾 **Export & Reset:** Možnost exportovat upravenou databázi do JSON souboru a resetovat data do továrního nastavení.
- 🌓 **Tmavý & Světlý režim:** Moderní design s glassmorphismem přizpůsobený pro oba barevné režimy.
- ⚡ **Rychlost:** Bleskové načítání díky čisté implementaci v HTML5, moderním CSS a Vanilla JavaScriptu (bez těžkých frameworků).

## Spuštění projektu lokálně

Pro spuštění stačí otevřít adresář projektu a spustit jakýkoliv lokální webový server. Například:

```bash
python3 -m http.server 8000
```

Následně otevřete prohlížeč na adrese [http://localhost:8000](http://localhost:8000).
